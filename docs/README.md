# LeanWarp documentation

- [Getting started](getting-started.md): sign in, connect a project and verify a proof.
- [Use with an agent](agents.md): install the skill or configure MCP.
- [CLI reference](../src/leanwarp_cloud/skills/leanwarp/references/usage.md#commands): commands and workspace reuse.

- [Python](../src/leanwarp_cloud/skills/leanwarp/references/usage.md#python): install the library and use a project session.
- [Recovery](../src/leanwarp_cloud/skills/leanwarp/references/usage.md#recovery): lost responses, timeouts and conflicting edits.
- [Credentials, credit and limits](../src/leanwarp_cloud/skills/leanwarp/references/usage.md#credentials-credit-and-limits).

The reference is also bundled with the installed SDK. Read it without a browser
or account using `leanwarp skill --reference`. For command arguments, run
`leanwarp --help` or `leanwarp COMMAND --help`.
